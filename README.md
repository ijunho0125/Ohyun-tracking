# 오현고 컴퓨팅 클럽 모션 아케이드

웹캠으로 손과 몸을 읽어 디노 런·모션 테트리스·밸런스 볼을 플레이하는 PC용 웹앱입니다. 패드에서 그린 그림을 저장하면 다른 컴퓨터의 디노 런 캐릭터에 바로 적용됩니다. React·TypeScript·Vite와 Node.js 그림 저장 서버를 사용하며 별도 데이터베이스나 계정은 필요하지 않습니다. 게임은 PC용이고 `/draw` 그리기 화면은 패드·터치 입력을 지원합니다.

## 실행

Node.js 22.12 이상과 Chrome을 권장합니다.

```powershell
cd C:\Users\user\Documents\tracking
npm.cmd ci
npm.cmd run setup:models
npm.cmd run dev
```

브라우저에서 **http://127.0.0.1:5173/** 를 엽니다. 이미 의존성과 모델이 있다면 마지막 명령만 실행하면 됩니다. PowerShell 실행 정책에 영향받지 않도록 `npm.cmd`를 사용합니다. 실행 중에는 터미널을 열어두세요. 포트 5173을 이미 사용한다면 기존 서버를 종료하거나 `vite.config.ts`에서 포트를 변경하세요.

공식 모델 두 개는 `public/models`에 포함되어 있습니다. `setup:models`는 파일이 있으면 해시를 검증하고, 없으면 Google에서 모델을 내려받습니다. JS·WASM은 dev/build 스크립트가 설치된 패키지에서 복사합니다. 처음 설치하거나 모델을 내려받을 때 인터넷이 필요합니다.

카메라는 localhost 또는 HTTPS 주소에서 브라우저 권한을 허용해야 사용할 수 있습니다. 일반 HTTP LAN 주소와 HTML 파일 직접 열기는 지원하지 않습니다. 카메라 없이 키보드로 세 게임을 할 수도 있습니다.

## 패드에서 그려서 다른 컴퓨터에 바로 적용하기

게임 컴퓨터에서 서버를 실행하고 패드와 컴퓨터를 같은 Wi-Fi에 연결합니다.

```powershell
npm.cmd run dev:lan
```

1. 게임 컴퓨터에서는 `http://localhost:5173/`를 열고 디노 런을 선택합니다.
2. 패드에서는 `http://게임컴퓨터의LAN주소:5173/draw`를 엽니다. 예: `http://192.168.0.10:5173/draw`. 이 화면은 카메라를 사용하지 않으므로 로컬 Wi-Fi의 HTTP에서도 그리기와 저장이 가능합니다. Windows 방화벽에서 해당 서버의 사설 네트워크 접속을 허용해야 할 수 있습니다.
3. 손가락·펜으로 그린 후 **이미지 저장**을 누릅니다. 그림을 파일로 내려받지 않고 사이트 서버에 저장하며, 열려 있는 디노 런에 실시간으로 적용합니다. ‘이미지 사용’이나 추가 업로드는 필요하지 않습니다.
4. 컴퓨터에서 기존 게임 시작 버튼을 누릅니다. 그림 저장은 게임을 자동 실행하거나 게임 화면을 강제로 이동하지 않습니다.

같은 서버에 연결된 디노 런은 마지막으로 저장한 그림을 공유합니다. 새로고침·게임 재진입·일시적인 연결 끊김 후에도 서버의 최신 선택을 받습니다. 인터넷으로 접속할 때는 같은 HTTPS 서버 주소를 사용합니다. 그림 원본과 PNG는 서버의 `.character-data/`에 보관되며 `CHARACTER_DATA_DIR` 환경 변수로 저장 위치를 바꿀 수 있습니다. 서버 재배포 시에도 이 경로를 영구 볼륨에 보존하세요. 서버가 꺼져 있으면 저장 실패 안내를 표시하고 다시 저장할 수 있도록 패드의 그림을 유지합니다.

## 손으로 메뉴 선택

1. 설정에서 메뉴를 조작할 손을 지정합니다. 기본값은 오른손이며 다른 손으로 자동 대체하지 않습니다.
2. 손을 펴서 커서를 움직입니다. 검지 끝 대신 손목과 네 손가락 뿌리 관절의 평균인 손바닥 중심을 사용합니다.
3. 카드 위에 머문 뒤 주먹을 쥡니다. 손을 접기 시작하면 커서와 선택 대상이 고정됩니다.
4. 한 번 선택한 뒤에는 손을 다시 펴야 다음 선택이 가능합니다. 주먹 유지 중에는 반복 선택하지 않습니다.

기본값은 손 펴기 3프레임, 대상 위 머무르기 240ms, 주먹 확인 3프레임 이상 및 180ms 유지입니다. 설정에서 유지 시간·연속 프레임·머무르기·보정 계수를 조절할 수 있습니다. 작거나 잘린 손, 신뢰도가 낮은 관절 결과는 선택에 사용하지 않습니다. 손 소실·화면 전환·모달 변경 때 선택 준비를 초기화합니다.

영상과 커서는 X축을 함께 반전합니다. 카메라의 중앙 영역을 PC 화면 전체로 매핑해 가장자리 버튼도 선택하기 쉽게 합니다. 검지 클릭과 엄지·검지 집기 입력 및 관련 설정은 제거했습니다.

모션으로 연습·플레이·카운트다운·자세 보정 중에는 게임이 모션 입력을 독점합니다. 메뉴를 사용하려면 Esc 또는 화면 버튼으로 일시정지하세요. 마우스와 키보드는 계속 사용할 수 있습니다.

## 게임 조작

게임을 선택하면 사이트 메뉴와 푸터를 숨기고 화면 전체를 게임에 사용합니다. 카메라는 게임 위에 작은 창으로 겹쳐 표시하며 좌우 위치 변경·접기·확대가 가능합니다. 게임에 진입하면 바로 소리를 켜고, 로비·일시정지·소리·전체화면 버튼을 제공합니다. 브라우저가 자동 재생을 막으면 ‘소리 시작’을 누르면 됩니다. 실제 전체화면 진입이 제한되는 경우에도 브라우저 영역을 가득 채웁니다. 로비 복귀 시 전체화면과 오디오를 정리합니다. 종료와 재시작은 일시정지 화면에 있습니다.

디노와 테트리스는 `temp_gameFile/공룡게임.html`, `temp_gameFile/테트리스.html`의 실제 게임 스크립트를 사용합니다. 디노의 배경·장애물·아이템과 테트리스의 EASY/HARD·방해 블록·NEXT·이인자 효과를 유지합니다. 밸런스 볼은 해당 폴더에 원본이 없어 기존 구현을 사용합니다.

디노는 모션 모드의 기본 달리기를 약 1.67배, 키보드는 약 1.33배 빠르게 조정했습니다. 시작 2초·재개 1초 동안 보호하며, 모션 점프 직후 450ms·숙이기 시작 300ms·착지 후 180ms의 충돌 여유를 줍니다. 충돌 뒤 약 140ms 안에 도착한 실제 모션 입력도 받아줍니다. 보호받은 장애물은 자연스럽게 지나가며, 같은 동작을 유지한다고 무적 시간이 계속 늘어나지는 않습니다. 이 기능은 게임 판정을 보정하며 카메라 인식 성공률의 측정값은 아닙니다.

모든 페이지는 PC 창 안에서 스크롤 없이 사용합니다. 설정은 카메라·손 조작·게임·도움말 탭, 그림 편집은 그림·자르기·배경 제거 탭, 기술 체험관은 모션·그림 탭으로 나뉩니다. 캐릭터 보관함은 이전/다음 페이지를 사용합니다. 검증한 최소 창 크기는 1280×640입니다.

로비의 큰 시작 문구 배너는 삭제하고 게임 카드와 카메라 연결을 바로 표시합니다.

정보축전 현장에서 읽기 쉽도록 게임 카드 제목은 32px, 주요 안내·메뉴·버튼은 20px, 설정과 편집 도구는 18px 중심으로 확대했습니다. 기존 버건디·크림·호랑이 로고는 유지하며 보조 글자와 경계를 진하게 바꿨습니다. 키보드 초점과 본문 바로가기, 색과 함께 표시하는 인식 상태, 소리 켜기·끄기를 제공합니다. 이번 검사는 글자·대비·키보드 동작에 대한 것이며 시각장애인 사용성 평가나 전체 게임의 비시각적 조작을 인증한 것은 아닙니다.

| 게임 | 모션 | 키보드 |
| --- | --- | --- |
| 디노 런 | 어깨와 골반이 함께 상승하면 점프, 몸을 낮추면 숙이기 | Space / ↑ 점프, ↓ 숙이기 |
| 디노 앉은 모드 | 손목을 어깨 위로 올리면 점프 | ↓ 숙이기 |
| 모션 테트리스 | 왼손만 주먹: 왼쪽, 오른손만 주먹: 오른쪽, 양손 주먹: 즉시 바닥까지 낙하, 점프: 회전, 앉기: 소프트 드롭 | ← → 이동, ↑ 회전, ↓ 빠른 낙하, Space 즉시 낙하 |
| 밸런스 볼 | 상체를 좌우로 기울여 판 조절 | ← → 기울이기, 놓으면 수평 |

몸 점프는 몸통 길이 대비 어깨 6%·골반 4%의 작은 상승부터 확인하며, 빠른 상승은 두 샘플의 몸 중심 속도로 더 일찍 감지합니다. 높이와 속도를 몸통 길이로 나눠 카메라와의 거리에 따른 차이를 줄입니다. 미세한 떨림·한 프레임의 좌표 튐·어깨만 움직이는 동작은 걸러내고, 서 있거나 앉아 있는 자세로 돌아오면 다음 점프를 준비합니다. 앉은 뒤 바로 점프해도 인식하며, 점프가 확인되면 앉기 입력부터 해제합니다. 앉았다가 일어서기만 하는 동작은 점프로 처리하지 않습니다. 같은 판정을 디노 점프와 테트리스 회전에 사용합니다.

테트리스는 양손을 펴서 준비합니다. 왼손만 주먹이면 왼쪽, 오른손만 주먹이면 오른쪽으로 이동하고 유지하면 반복합니다. 양손 주먹은 조각을 바닥까지 한 번에 내리며, 계속 쥐어도 다음 조각을 반복해서 내리지 않습니다. 다시 양손을 펴면 다음 낙하가 가능합니다. 손목 기울기는 조작에 사용하지 않습니다. 편하게 선 자세로 양손·어깨·골반을 보여 30개의 안정 자세 샘플로 보정합니다. 점프하면 한 번 회전하며, 서 있거나 앉아 있는 자세로 돌아오면 다음 회전이 가능합니다. 앉아 있는 동안 소프트 드롭을 유지하고 일어서면 해제합니다. 손 추적 소실·화면 전환 시 유지 입력과 점프 준비를 초기화합니다. 디노와 밸런스도 30개의 안정 자세 샘플로 보정합니다. 게임의 준비·연습·3초 카운트다운·일시정지·재개·종료·재시작·로비 복귀를 지원합니다. 유효 모션 입력이 1.4초 동안 없거나 탭·포커스를 벗어나거나 중앙 모달을 열면 플레이를 일시정지합니다.

## 호랑이 튜토리얼과 트래킹

튜토리얼은 손 보여주기 → 손바닥 커서 이동 → 주먹 선택 → 손 펴기 → 게임 연습 순서입니다. 실제 동작으로 자동 진행하거나, 다음 버튼 위에 손을 편 커서를 0.9초 올려 직접 넘어갈 수 있습니다. 마우스와 주먹 선택도 가능합니다. 직접 넘긴 단계는 따로 표시하며, 커서를 계속 둬도 다음 화면까지 자동으로 연속 선택하지 않습니다. 게임 조작 연습이 끝나면 잠시 멈추고 손바닥으로 연습 마치기·로비 이동을 선택할 수 있습니다. 연습 완료 체크는 실제 게임 명령으로 채워야 합니다.

카메라 미리보기는 실제 영상 비율을 유지하며 영상과 관절 Canvas를 같이 좌우 반전합니다. 실제 인식 좌표로 점과 연결선을 표시하고, 확대와 표시 켜기·끄기를 지원합니다. 결과가 없거나 마지막 프레임이 650ms 이상 오래되면 관절 표시를 지웁니다. 기술 체험관에서는 AI가 추정한 관절 위치와 프로그램의 굽힘·연속 프레임·시간 판정을 구분해 보여줍니다.

## 그림 한 장으로 플레이

내 그림 화면에서 PNG·JPG·WebP 한 장을 등록합니다. 최대 15MB, 2,500만 픽셀이며 투명 PNG도 지원합니다. 잘라내기·크기·좌우 뒤집기·발 기준점을 조절하고 단색 배경을 제거할 수 있습니다. 버건디색 점이 발 기준점입니다. 복잡한 사진 배경의 자동 분리는 지원하지 않습니다.

달리기·점프·착지·숙이기는 같은 그림의 가로·세로 비율, 회전, 위치로 표현합니다. 여러 동작 그림이나 스프라이트 시트는 필요하지 않습니다. 발 기준점을 중심으로 렌더링하고 장식 변형과 충돌 계산을 분리합니다. 점프 물리는 입력을 받은 즉시 시작합니다. 내 그림 편집기와 `/draw`의 **이미지 저장**은 서버 저장과 디노 캐릭터 선택을 한 번에 처리합니다. 이전 버전에서 브라우저에 보관한 그림도 보관함에 표시하고, 선택할 때 공유 서버로 가져옵니다.

## 구조와 저장

- `src/App.tsx`: 상단 메뉴·큰 게임 카드·메뉴 커서·선택 범위와 화면 전환.
- `src/motion/camera.ts`: 카메라 스트림, 권한 오류, 요청 취소, 추론 빈도와 Worker 생명주기.
- `src/motion/vision.worker.ts`: 로컬 MediaPipe Hand Landmarker / Pose Landmarker Lite, CPU·WASM 추론. 메뉴는 손, 테트리스 모션 플레이는 손+몸 모델을 같은 Worker에서 함께 사용하고 어깨·골반의 상승과 앉기를 판단합니다. 디노·밸런스는 몸 모델을 사용합니다.
- `src/motion/hands.ts`: 손바닥 좌표, 손가락 굽힘과 유효성, 주먹 선택 상태 머신, 양손 게임 입력.
- `src/motion/gestures.ts`: 자세 보정, 연속 상승·중립 복귀·기울기 판정.
- `src/motion/tetris.ts`: 양손 주먹 이동·즉시 낙하와 몸 점프 회전·앉기 소프트 드롭을 함께 처리합니다.
- `src/motion/nod.ts`: 이전 끄덕임 판정 모듈입니다. 현재 테트리스 조작에는 사용하지 않습니다.
- `src/components/CameraPanel.tsx`: 실제 영상 비율의 미리보기와 관절 오버레이.
- `src/games/source-games.ts`: 원본 HTML 게임을 불러와 모션 명령·시작·정지·재개·점수·그림을 연결하는 어댑터. 원본의 별도 RAF와 키 입력은 제거하고 앱의 단일 시계와 명령으로 실행합니다.
- `src/games/audio.ts`: 게임 선택 시 브라우저 오디오를 열고 원본 게임 음악·효과음과 밸런스 배경음을 같은 출력에 연결합니다. 종료 때 타이머·컨텍스트를 정리합니다.
- `src/festival.css`: 정보축전용 큰 글자·선명한 대비·게임 위 카메라 배치.
- `src/games/engines.ts`: 밸런스 볼 엔진. 디노와 테트리스는 `source-games.ts`에서 원본 HTML을 연결하며, 사용하지 않는 이전 이식본은 제거했습니다.
- `src/games/info.ts`: 로비와 게임 화면이 공유하는 게임 설명. 게임·그림 편집·튜토리얼·체험관 코드는 해당 화면을 열 때 불러옵니다.
- `src/games/character.ts`: 그림 한 장의 발 기준점 렌더링과 변형.

카메라 영상과 좌표는 녹화하거나 서버로 보내지 않습니다. 사용자가 저장한 그림 원본과 처리한 PNG는 다른 기기의 게임과 공유하기 위해 사이트 서버에 보관하고, 선택 변경은 SSE로 전달합니다. 설정과 최고 기록은 각 브라우저의 localStorage에 저장합니다. 브라우저 데이터를 지워도 서버의 그림은 유지되며 보관함의 삭제 버튼으로 지울 수 있습니다. 최초 설치와 모델 다운로드 시 npm·Google에 파일을 요청하고, 방문 시 호스팅 서버에는 일반 파일 요청이 발생합니다.

공식 로고·색상 토큰·PC 화면 원칙은 [DESIGN.md](DESIGN.md)에 정리했습니다. 공식 로고, 별도의 픽셀 호랑이 안내자, 사용자 그림은 서로 다른 자산입니다. 원본 게임 HTML은 `temp_gameFile`에 보존했습니다. Vite가 원본을 번들에 포함하고 로컬 `srcdoc` iframe에서 실행합니다. 원본의 외부 Tailwind CDN·Google Fonts 요청은 제거했으며 게임 실행에 외부 페이지나 운영체제 키 입력은 사용하지 않습니다. iframe은 카메라에 접근하지 않고 앱에서 판정한 게임 명령만 받습니다.

## 검사와 빌드

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

개발 서버 실행 중 다른 터미널에서 PC 브라우저 통합 검사를 실행할 수 있습니다. 로컬 Chrome을 사용합니다.

```powershell
npm.cmd run test:browser
npm.cmd run test:motion
npm.cmd run test:dino-motion
npm.cmd run test:tracking-speed
npm.cmd run test:vision
npm.cmd run test:character-sync
npm.cmd run test:right-hand
npm.cmd run test:festival
npm.cmd run test:loading
```

`test:loading`은 첫 화면에서 보조 화면 코드를 요청하지 않는지, 느린 화면 전환에서도 Canvas 오류가 없는지, 게임을 떠날 때 오디오가 즉시 정리되는지 확인합니다. `TEST_URL`을 미리보기 서버 주소로 지정하면 프로덕션 빌드에서도 같은 검사를 실행할 수 있습니다.

일반 검사는 화면 잘림·전체화면·원본 게임·키보드·PNG 업로드·저장·모델 로드를, 모션 검사는 합성 카메라 스트림과 모의 관절 좌표로 주먹·원본 테트리스 조작·트래킹·튜토리얼·자원 정리를 시험합니다. 오른손 검사는 공식 손 사진과 실제 모델·Worker로 커서와 관절 표시를 시험합니다. 손 관절의 SDK 기본값 `visibility: 0`은 손 소실로 처리하지 않으며 몸의 가시성 판정과 분리합니다. iframe 안의 `motionGame`은 실제 게임 제어 인터페이스이며 테스트도 같은 인터페이스로 상태를 확인합니다. `/tests/worker-smoke.html`에서는 실제 모델의 빈 합성 프레임 추론과 Canvas·IndexedDB를 시험합니다. 검사 HTML은 프로덕션 빌드에 포함하지 않습니다.

행사 검사는 글자 크기·텍스트 대비·초점·카메라 오버레이와 실제 Web Audio 분석기의 출력, 게임 진입·음소거·일시정지·복귀 시 오디오 생명주기를 확인합니다. 실제 스피커 음량이나 행사장 소음 환경을 측정한 것은 아닙니다.

검증 결과와 실제 카메라에서 확인해야 할 부분은 [docs/VALIDATION.md](docs/VALIDATION.md)에 있습니다. 모의 좌표나 빈 영상 시험을 실제 사람의 인식 정확도·지연·FPS 시험으로 해석하면 안 됩니다.

기기 간 그림 공유에는 Node 서버가 필요합니다. `npm.cmd run build` 후 `npm.cmd start`를 실행하면 `dist/` 정적 파일과 `/api/characters`를 함께 제공합니다. 기본 포트는 5173이며 `PORT`와 `HOST` 환경 변수로 바꿀 수 있습니다. `dist/`만 정적 호스팅에 올리면 기기 간 저장·자동 적용은 동작하지 않습니다. 운영에서는 도메인 루트에 HTTPS 프록시를 연결하고 SSE 응답 버퍼링을 끄며 `.character-data/`를 영구 저장소에 연결하세요. `dist/`, `dist-server/`, 그림 데이터 경로가 필요하고 런타임 npm 패키지는 추가로 필요하지 않습니다. `.wasm`은 서버에서 `application/wasm`으로 제공합니다. 이 작업에서 운영 배포는 하지 않았습니다. 외부 라이브러리·모델 고지는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)를 참고하세요.
